# Suggested GitHub issue labels

| Label | Color (hint) | Use |
|-------|----------------|-----|
| `physics` | blue | Atmosphere, activity tables, CNT, efficiency |
| `ui` | purple | GUI, sliders, Win95 chrome |
| `literature` | green | Research xref, citations, golden rank intent |
| `builder` | orange | Molecular upload / future molecular builder |
| `ci` | gray | Tests, fixtures, Actions |
| `docs` | yellow | PROJECT.md, demos, one-pager |
| `bug` | red | Incorrect behavior |
| `enhancement` | cyan | Non-breaking features |

Create via GitHub UI or `gh label create`.
