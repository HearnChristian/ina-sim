# ☁️ SuperCool Liquid Water Calculator

Calculate potential water condensation from clouds using artificial seeding agents!

## Features
- Real atmospheric physics calculations
- Multiple seeding agents (AgI, NaCl, CaCl₂, KI, and experimental testosterone!)
- Interactive web interface
- Mobile responsive design

## Usage
Open `index.html` in your browser or visit the live demo!

## The Science
Uses Magnus formula for saturation vapor pressure, ideal gas law for air density, and Köhler theory principles for droplet formation efficiency.

## Seeding Agents
- **Silver Iodide (AgI)**: Most effective, optimal at -7°C
- **Sodium Chloride (NaCl)**: Hygroscopic, works at -12°C  
- **Calcium Chloride (CaCl₂)**: Good efficiency at -10°C
- **Potassium Iodide (KI)**: Moderate efficiency at -8°C
- **Testosterone**: Experimental agent (surprisingly effective!)

Built for learning atmospheric science and cloud physics! 🌦️
